# 품질 기준

성능, 접근성, 지원 환경 기준입니다. 새 페이지와 변경은 이 기준을 지킵니다.

## 성능

Core Web Vitals "좋음" 기준을 목표로 합니다. 모바일 측정값 기준입니다.

| 지표 | 목표 |
|---|---|
| LCP (가장 큰 콘텐츠가 보이는 시간) | 2.5초 이하 |
| INP (입력 반응 시간) | 200ms 이하 |
| CLS (레이아웃 흔들림) | 0.1 이하 |

- 첫 화면에 보이는 큰 이미지(LCP 이미지)는 `next/image`에 `fetchPriority="high"` 또는 `loading="eager"`를 줍니다. `priority`는 Next.js 16에서 deprecated입니다.
- 이미지에는 크기(`width`, `height` 또는 `fill` + 부모 크기)를 정해 레이아웃이 흔들리지 않게 합니다.
- 폰트는 사이트가 직접 제공합니다. 외부 CDN의 폰트 CSS를 링크하지 않습니다. 불러오는 방법은 [design-system.md](design-system.md#타이포그래피)에 있습니다.
- 측정 방법(Lighthouse, Vercel Speed Insights 등)은 미정입니다.

## 접근성

WCAG 2.2 AA를 목표로 합니다.

- 이미지에는 의미 있는 `alt`를 씁니다. 꾸밈용 이미지는 `alt=""`입니다.
- 글자와 배경의 명도 대비는 본문 4.5:1, 큰 글자 3:1 이상입니다.
- 키보드만으로 모든 링크와 버튼을 쓸 수 있고, 포커스 표시가 보여야 합니다.
- 제목은 페이지마다 `h1` 하나로 시작하고 단계를 건너뛰지 않습니다.
- 클릭되는 요소는 `<a>`나 `<button>`을 씁니다. `<div onClick>`을 쓰지 않습니다.
- 움직이는 효과는 `prefers-reduced-motion`을 존중합니다.

## 지원 환경

| 항목 | 기준 |
|---|---|
| 브라우저 | Next.js 16 기본 지원 범위: Chrome 111+, Edge 111+, Firefox 111+, Safari 16.4+ |
| 화면 너비 | 360px부터 깨지지 않음 |
| 기기 | 모바일 우선. 모바일과 데스크톱 모두 확인 |

- 지원 범위를 넓히거나 줄이면 이 표를 고칩니다.
