# 매장 찾기

- URL: `/stores`
- 상태: 시안

## 목적

메인의 공간 이미지와 검색에서 이동해 지역별 매장을 찾고 주소·연락처·개점(예정)일을 확인합니다.

## 섹션

| 순서 | 섹션 | 내용 | 사용 컴포넌트 |
|---|---|---|---|
| 1 | 소개 | 제목 `가까운 Dozy를 찾아보세요.`, 설명, 예시 데이터일 때 명시적인 안내 | 페이지 |
| 2 | 검색·결과 | 지역 선택, 매장명·주소 검색, 결과 수, 매장 정보, 페이지 이동 | `StoreSearchForm`, `StoreResults` |

- 메인의 검색은 `/stores?q=검색어`로 이동합니다. 비어 있으면 전체 매장입니다.
- URL의 `q`, `sido`, `page`를 읽습니다. 검색어는 공백과 대소문자를 무시하고 매장명·도로명주소·상세주소·시도·시군구를 합친 문자열에서 찾습니다. 띄어 쓴 여러 단어는 각각 포함되는지도 확인합니다(예: `서울 잠실`).
- 시도는 데이터에 있는 정식 명칭만 선택하며 텍스트 검색과 함께 적용합니다. 검색 제출은 페이지 번호를 초기화합니다.
- 한 페이지에 12곳, 원본 데이터 순서입니다. 페이지 링크는 검색 조건을 유지합니다. 잘못된 페이지 번호는 첫 페이지, 범위를 넘으면 마지막 페이지로 제한합니다.
- 결과 수는 `role="status"`로 알립니다. 데이터가 없거나 검색 결과가 없으면 각각 준비·결과 없음 안내를 표시합니다. 전체 매장 보기로 조건을 해제합니다.
- 정보는 매장명, 도로명주소, 상세주소(있을 때), 우편번호, 전화번호, 개점(예정)일입니다. 제공하지 않은 영업시간을 지어서 표시하지 않습니다.
- 예시 전화번호는 일반 텍스트입니다. 실제 데이터에서만 전화·지도 링크를 제공합니다.

## 데이터

| 데이터 | 출처 | 갱신 |
|---|---|---|
| 실제 매장 | `src/content/stores.ts` (아직 비어 있음) | 배포 시 |
| 예시 100개 | `src/mocks/stores.json` → `src/mocks/stores.ts` | 배포 시 |
| 문구 | `src/content/stores-ui.ts` | 배포 시 |

- 선택은 `src/lib/content.ts`의 `getStores()`. 예시 데이터 설정은 [configuration.md](../configuration.md)의 `SHOW_DEMO_DATA`를 따릅니다.
- `Store`: `name`, `address`(`roadAddress`, `detailAddress: string | null`, `postalCode`, `sido`, `sigungu`), `phone`, `openingDate`(YYYY-MM-DD). ID·매장 코드·영업 상태는 포함하지 않습니다. 매장명은 고유하며 우편번호는 문자열입니다.
- 예시 주소·우편번호는 공개 주소 검색으로 대조했고, 매장명·전화·개점일은 가상입니다. 상세주소는 모두 null입니다. 특정 주소에 Dozy 매장이 있음을 뜻하지 않습니다.

## 렌더링

SSG. 제목·안내는 서버에서 출력하고 검색 결과는 `Suspense` 안에서 URL을 읽는 클라이언트 컴포넌트로 구성합니다. 서버에서 파일 시스템을 읽는 이미지 처리는 메인에만 있습니다.
