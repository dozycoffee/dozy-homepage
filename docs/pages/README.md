# 페이지

사이트맵과 페이지 문서 규칙입니다. 페이지 하나의 내용은 각 페이지 문서에 있습니다.

## 사이트맵

URL과 문서의 대응은 이 표에만 씁니다. 페이지를 추가하거나 URL을 바꾸면 이 표를 같은 변경에서 고칩니다.

| URL | 페이지 | 문서 | 상태 | sitemap.xml | 단계 |
|---|---|---|---|---|---|
| `/` | 메인 | [home.md](home.md) | 시안 | 포함 | 1 |
| (없는 주소) | 404 | [layout.md](layout.md#404) | 구현됨 | 제외 | 1 |
| `/news` | 소식 목록 | 없음 | 예정 | | 1 |
| `/news/[id]` | 소식 상세 | 없음 | 예정 | | 1 |
| `/privacy` | 개인정보처리방침 | 없음 | 예정 | | 1 |
| `/brand` | 브랜드 이야기 | 없음 | 예정 | | 2 |
| `/menu` | 메뉴·원두 | 없음 | 예정 | | 2 |
| `/stores` | 매장 찾기 | 없음 | 예정 | | 2 |
| `/franchise` | 가맹 안내·문의 | 없음 | 예정 | | 3 |
| `/terms` | 이용약관 | 없음 | 예정 | | 3 |

- 상태: `예정` (사이트맵에만 있고 라우트가 없음), `기획` (문서가 있음), `시안` (화면은 있고 문구·사진·데이터가 임시), `구현됨`.
- "준비 중" 자리 페이지는 두지 않습니다. 내용을 만들 때 라우트를 추가합니다.
- 단계: 1 공개 전에 필요, 2 브랜드 사이트로서 기대되는 것, 3 사업 방향에 따라 필요.
- 페이지 작업을 시작할 때 문서를 만들고 상태를 `기획`으로 바꿉니다. 빈 문서를 미리 만들지 않습니다.
- 헤더 메뉴는 지금 메인의 섹션(`/#brand` 등)으로 이동합니다 ([ADR-0010](../adr/0010-single-page-home-sections.md)). 상세 페이지를 만들면 `src/lib/navigation.ts`와 [layout.md](layout.md)를 함께 고칩니다.
- 이용약관·개인정보처리방침 링크는 실제 문서 주소를 `src/content/site.ts`에 넣었을 때만 푸터에 보입니다.
- `sitemap.xml` 열이 `포함`인 페이지는 `src/app/sitemap.ts`의 목록과 같아야 합니다 ([seo.md](../seo.md#sitemap-robots)).

**페이지별로 먼저 정할 것**

| 페이지 | 먼저 정할 것 |
|---|---|
| `/news`, `/news/[id]` | 소식 데이터 출처 (CMS, 별도 API 등) |
| `/privacy` | 수집하는 개인정보 (분석 도구, 문의 폼). 개인정보를 받는 기능이 생기기 전에 있어야 함 |
| `/brand` | 실제 브랜드 문구와 사진 |
| `/menu`, `/stores` | 데이터 출처. catalog-api에는 공개 API가 아직 없음 |
| `/franchise` | 가맹 모집 여부. 문의 폼을 두면 개인정보 수집 동의 필요 |
| `/terms` | 회원·주문 기능 여부 |
- 모든 페이지 공통 요소(헤더, 푸터, 404)는 [layout.md](layout.md)에 있습니다.

## 파일 이름

파일 이름은 URL 경로를 따릅니다. URL만 보고 문서를 찾을 수 있게 합니다.

| URL | 파일 |
|---|---|
| `/` | `home.md` |
| `/about` | `about.md` |
| `/stores` | `stores.md` |
| `/stores/[id]` | `stores-detail.md` |
| `/brand/story` | `brand-story.md` |
