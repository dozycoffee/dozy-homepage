# 페이지

사이트맵과 페이지 문서 규칙입니다. 페이지 하나의 내용은 각 페이지 문서에 있습니다.

## 사이트맵

URL과 문서의 대응은 이 표에만 씁니다. 페이지를 추가하거나 URL을 바꾸면 이 표를 같은 변경에서 고칩니다.

| URL | 페이지 | 문서 | 상태 |
|---|---|---|---|
| `/` | 메인 | [home.md](home.md) | 임시 페이지 |

- 상태: `기획` (문서만 있음), `임시 페이지` (자리만 있음), `구현됨`.
- 모든 페이지 공통 요소(헤더, 푸터, 404)는 [layout.md](layout.md)에 있습니다.

## 파일 이름

파일 이름은 URL 경로를 따릅니다. URL만 보고 문서를 찾을 수 있게 합니다.

| URL | 파일 |
|---|---|
| `/` | `home.md` |
| `/about` | `about.md` |
| `/stores` | `stores.md` |
| `/stores/[id]` | `stores-detail.md` |
| `/brand/story` | `brand-story.md` |
