# 메뉴

- URL: `/menu`
- 상태: 시안 (메뉴와 가격은 기획안이며 대부분 상품 사진은 미확정)

## 목적

방문자가 전체 메뉴를 분류하거나 검색해서 조회합니다. 메인은 대표 음료만 소개하고 이 페이지로 연결합니다. 주문·옵션 선택·결제는 범위에 포함하지 않습니다.

## 섹션

| 순서 | 섹션 | 내용 | 사용 컴포넌트 |
|---|---|---|---|
| 1 | 제목 | `src/content/menu-ui.ts`의 `menuPage` 문구, h1 | `MenuPage` |
| 2 | 메뉴 조회 | 이름·설명 검색, 전체(첫 선택)·시그니처·대분류 탭, 소분류별 상품 카드와 결과 수 | `MenuCatalogView`, `MenuTabs` |

## 동작

- 이름과 설명에서 검색합니다. 공백·대소문자를 무시하며 입력 즉시 결과를 갱신합니다.
- 전체 탭은 JSON 순서대로 전체 상품을 표시합니다. 시그니처 탭은 `tagNames`에 시그니처 태그가 있는 상품을 표시하며, 해당 상품이 있을 때만 표시합니다. 대분류 탭은 JSON의 소분류별로 묶습니다.
- 상품 없는 소분류는 숨깁니다. 선택한 탭에 검색 결과가 없으면 검색 결과 없음 문구를 표시합니다. 검색어가 없으면 메뉴 준비 중 문구를 표시합니다.
- 각 탭에 해당하는 결과 수를 `role=status`로 표시합니다.
- 탭은 좌우 화살표·Home·End로 이동합니다. 모바일에서는 필요할 때 탭 줄을 바꿔 가로 넘침을 방지합니다.
- 카드는 모바일 2열, 태블릿 3열, 데스크톱 4열. 이름·설명·기본 가격을 표시합니다. 이미지가 null이면 자리만 유지합니다.
- 제목 구조: 페이지 h1 → 목록 h2(화면 읽기용) → 소분류/그룹 h3 → 상품 h4.
- 로딩·오류·재시도·빈 목록·요청 취소·15초 제한은 공용 조회 훅과 상태 컴포넌트가 처리합니다.

## 데이터

| 데이터 | 출처 | 갱신 |
|---|---|---|
| 상품·분류·옵션·그룹 | [data-sources.md](../data-sources.md)의 메뉴 카탈로그 계약 | 진입·재시도 시 브라우저 조회 |
| 문구 | `src/content/menu-ui.ts` | 배포 시 |

- 가격과 상품은 기획안입니다. 시그니처 태그는 탭 필터에 사용합니다. 다른 태그와 옵션은 데이터에 보존하지만 선택 UI는 없습니다.

## 렌더링

골격은 SSG, 상품은 클라이언트 조회. 초기 HTML에는 상품 목록이 없습니다. 메인과 같은 API 클라이언트를 사용합니다.
