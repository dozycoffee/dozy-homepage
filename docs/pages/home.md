# 메인

- URL: `/`
- 상태: 시안 (화면과 동작은 구현됨. 사진, 실제 메뉴·매장·소식 데이터, 회사 정보가 없음)

## 목적

`www.dozy.kr`로 들어온 방문 고객에게 메뉴와 매장 정보를 주고, 브랜드 공간과 출시 예정 오더앱을 소개합니다. 예비 점주는 가맹 안내로 이어집니다. 구성 이유는 [ADR-0010](../adr/0010-single-page-home-sections.md)에 있습니다.

- 범위: 메인 페이지와 공통 헤더·푸터. 상세 페이지, 주문, 가맹 상담 접수는 별도 작업입니다.
- GitHub, 개발 프로젝트, 주문관리·WMS·POS 등 기술 콘텐츠를 넣지 않습니다.

## 섹션

## 동작

**메뉴 탭**

- WAI-ARIA 탭 패턴입니다. 좌우 화살표, `Home`, `End`로 탭을 옮기고 바로 선택됩니다.
- 상세 주소(`detailUrl`)가 있는 카드만 링크이며 카드 전체를 누를 수 있습니다.
- 선택한 카테고리에 메뉴가 없으면 `메뉴 정보를 준비하고 있습니다.`를 보여 줍니다.

**매장 검색**

- 검색 버튼이나 `Enter`를 누르면 결과를 바꿉니다. 검색어가 비어 있으면 전체 매장입니다.
- 검색어는 공백을 지우고 대소문자를 무시해 지역, 매장명, 주소에 들어 있는지 봅니다.
- 결과 위에 `매장 {n}곳`을 보이고 `role="status"`로 화면 읽기 프로그램에 알립니다.
- 결과가 없으면 `검색 조건에 맞는 매장이 없습니다.`, 매장 데이터가 하나도 없으면 `매장 정보를 준비하고 있습니다.`를 보여 줍니다.
- 지도 API를 쓰지 않습니다. 외부 주소 링크는 새 창으로 열고 "(새 창)"을 화면 읽기용으로 붙입니다.

**소식**

- 주소(`url`)가 있는 게시물만 링크입니다. 소식이 없으면 `새로운 소식을 준비하고 있습니다.`를 보여 줍니다.
- 이미지가 없어도 같은 비율의 자리가 남고 제목·날짜로 읽을 수 있습니다.
- 날짜는 `2026. 10. 01.` 형식(`ko-KR`, 한국 시간)입니다.

**가맹 안내**

- 링크 목적지는 `siteConfig.links.franchise`(`src/content/site.ts`)입니다. 값이 없으면 링크 대신 상태 문구 `가맹 안내 준비 중`을 보여 줍니다.

| 화면 확인용 예시 | `src/mocks/stores.ts`, `news.ts`. `SHOW_DEMO_DATA=true`일 때만 ([configuration.md](../configuration.md#환경-변수)) | 배포 시 |

필드 (형태는 `src/content/types.ts`)

| 데이터 | 필드 | 선택 필드 |
|---|---|---|
| 메뉴 | `id`, `category`(`coffee`, `signature`, `non-coffee`, `dessert`), `name`, `description` | `image`, `price`(원), `detailUrl` |
| 매장 | `id`, `name`, `region`, `address`, `hours` | `image`(없으면 `store-default.webp`), `detailUrl`, `mapUrl` |
| 소식 | `id`, `category`(`신메뉴`, `이벤트`, `신규 매장`), `title`, `date`(YYYY-MM-DD) | `image`, `url` |
| 이미지 (`image`) | `src`(`/assets/images/…`), `alt` | `position`(`object-position`) |

- 선택 필드가 없으면 해당 UI를 뺍니다. 빈 값, `#` 같은 주소는 링크로 만들지 않습니다(`src/lib/links.ts`).
- **실제로 확정된 정보만 `src/content/`에 넣습니다.** 예외는 임시 메뉴입니다(이름·설명만, 가격 없음). 판매 메뉴가 확정되면 바꿉니다. 메뉴 가격, 매장명·주소·영업시간, 행사·출시일·신규 매장 소식, 회사 정보, 가맹 조건(비용, 수익, 점포 수, 상담 전화)을 지어서 쓰지 않습니다.
- 메뉴 이미지 파일명(`menu-americano.webp` 등)은 이미지 자리 기준이며 판매 메뉴 확정을 뜻하지 않습니다.
- 데이터 조회는 `src/lib/content.ts`가 맡습니다. CMS나 API로 바꿀 때 이 함수만 바꿉니다.

## Dozy Order 제약

- 주문, 결제, 로그인, 앱 다운로드 기능과 버튼, 앱스토어 배지를 넣지 않습니다.
- 출시일, 할인, 적립, 픽업 기능 등 확정되지 않은 내용을 쓰지 않습니다.
- 스마트폰 이미지에 구체적인 주문 화면을 넣지 않습니다.
