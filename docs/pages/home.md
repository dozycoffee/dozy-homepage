# 메인

- URL: `/`
- 상태: 시안 (화면과 동작은 구현됨. 사진, 실제 메뉴·매장·소식 데이터, 회사 정보가 없음)

## 목적

`www.dozy.kr`로 들어온 방문 고객에게 메뉴와 매장 정보를 주고, 브랜드 공간과 출시 예정 오더앱을 소개합니다. 예비 점주는 가맹 안내로 이어집니다. 구성 이유는 [ADR-0010](../adr/0010-single-page-home-sections.md)에 있습니다.

- 범위: 메인 페이지와 공통 헤더·푸터. 전체 메뉴는 [메뉴 페이지](menu.md)로 연결합니다. 상품 상세, 주문, 가맹 상담 접수는 별도 작업입니다.
- GitHub, 개발 프로젝트, 주문관리·WMS·POS 등 기술 콘텐츠를 넣지 않습니다.

## 동작

**대표 메뉴 광고**

- 현재는 캐러셀 대신 시그니처 3종을 한 장에 담은 `three-signatures-menu.webp` 단일 이미지를 전체 폭·원본 비율로 표시하되 화면 높이(헤더 제외)를 넘지 않게 제한하고(위아래는 자르지 않고 줄여 보여 주며 남는 좌우는 흐린 같은 이미지로 채움) 누르면 `/menu`로 이동합니다(`menuSection.signaturesImage`). 아래 캐러셀 규칙은 `MenuAdCarousel`을 다시 쓸 때 기준입니다.

- 광고 순서·이미지 경로·대체 텍스트·제어 문구는 `src/content/home.ts`의 `menuSection`이 기준입니다. 상품 목록 API와 별도의 캠페인 이미지 설정입니다. 가격·상품 목록은 [메뉴 페이지](menu.md)에서 조회합니다.
- 광고에는 제품 이름과 카피, 서체가 이미지 안에 포함됩니다. 누룽지(큰 잔 측면)·흑임자(크림 오버헤드)·유자말차(왼쪽 잔 전체, 오른쪽 카피) 3종입니다. 실제 제품 촬영이 아닌 AI 생성 기획 이미지입니다.
- 데스크톱은 약 3:1의 넓은 광고 이미지를 섹션을 가득 채우도록(cover) 중앙 기준으로 표시합니다. 화면이 이미지보다 좁으면 좌우를, 더 넓고 낮으면 위아래를 잘라 좌우 여백이 생기지 않습니다. 모바일은 기존 세로형을 contain으로 표시합니다. 섹션 크기·이미지 규격은 [디자인 시스템](../design-system.md)이 기준입니다.
- 광고가 화면에 보일 때 8초마다 다음으로 좌우 전환하고 첫 광고로 순환합니다. 이미지 하단에 광고 수만큼 원형 버튼을 배치합니다. 버튼을 누르면 해당 인덱스로 이동하고 다음 자동 전환 시간을 다시 셉니다. 이전·다음 화살표와 숫자 표시·하단 링크 행은 없습니다.
- 데스크톱 원형 버튼은 이미지에 마우스를 올리거나 키보드 초점이 들어오면 나타납니다. 모바일·호버가 없는 기기에서는 항상 표시합니다. 선택된 버튼은 더 밝고 `aria-pressed=true`입니다.
- 마우스를 올리거나 키보드로 조작 중이거나 탭이 숨겨지거나 섹션이 화면 밖이면 자동 전환을 멈춥니다. 원형 버튼 클릭은 영구 일시정지하지 않습니다. 접근성을 위한 일시정지·자동 재생 버튼은 화면 읽기용으로 두고 키보드 초점 때 표시합니다.
- 움직임 줄이기 설정에서는 자동 재생·전환 애니메이션을 끕니다. 자동 재생 중에는 광고 변경을 화면 읽기 프로그램으로 반복 알리지 않습니다.
- 파일이 없는 광고는 제외합니다. 광고 이미지에는 카피와 이동 목적을 포함하는 대체 텍스트를 제공합니다. 이미지를 누르면 `/menu`로 이동합니다.
- 전체 조회·검색·시그니처 태그 및 카테고리 탭은 [메뉴 페이지](menu.md)가 기준입니다.

**매장 검색**

- 메인은 서로 다른 가상 매장 3곳의 AI 생성 시안 이미지를 표시합니다(도심 코너 매장 내부·동네 매장 외관·대학가 매장 내부). 기존 브랜드·가맹 이미지를 재사용하지 않습니다. 예시 100개나 실제 특정 지점의 사진을 뜻하지 않습니다. 이미지 파일·크기는 [디자인 시스템](../design-system.md#이미지)이 기준입니다.
- 사진 가운데 검색 상자의 버튼이나 `Enter`를 누르면 `/stores?q=검색어`로 이동합니다. 빈 검색은 전체 매장을 보여 줍니다.
- 결과·지역 선택·페이지 이동·주소·전화·개점일은 [매장 페이지](stores.md)에 있습니다 ([ADR-0017](../adr/0017-store-showcase-and-search-page.md)).

**소식**

- 주소(`url`)가 있는 게시물만 링크입니다. 소식이 없으면 `새로운 소식을 준비하고 있습니다.`를 보여 줍니다.
- 이미지가 없어도 같은 비율의 자리가 남고 제목·날짜로 읽을 수 있습니다.
- 날짜는 `2026. 10. 01.` 형식(`ko-KR`, 한국 시간)입니다.

**가맹 안내**

- 링크 목적지는 `siteConfig.links.franchise`(`src/content/site.ts`)입니다. 값이 없으면 링크 대신 상태 문구 `가맹 안내 준비 중`을 보여 줍니다.

- 매장·소식 조회는 `src/lib/content.ts`, 메뉴 조회는 `src/lib/menu-client.ts`가 맡습니다.

## Dozy Order 제약

- 주문, 결제, 로그인, 앱 다운로드 기능과 버튼, 앱스토어 배지를 넣지 않습니다.
- 출시일, 할인, 적립, 픽업 기능 등 확정되지 않은 내용을 쓰지 않습니다.
- 스마트폰 이미지에 구체적인 주문 화면을 넣지 않습니다.
