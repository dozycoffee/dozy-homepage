# 공통 레이아웃

모든 페이지에 들어가는 요소입니다. 페이지 문서에서는 다시 쓰지 않습니다.

- 구현 위치: `src/app/layout.tsx`
- 상태: 미정 (현재 레이아웃은 폰트와 기본 metadata만 있음)

## 헤더

| 항목 | 내용 |
|---|---|
| 로고 | 미정 |
| 메뉴 | 미정 |
| 모바일 | 미정 (햄버거 메뉴 여부) |
| 고정 여부 | 미정 |

## 푸터

| 항목 | 내용 |
|---|---|
| 회사 정보 | 미정 (상호, 대표자, 사업자등록번호, 주소, 연락처) |
| 링크 | 미정 (이용약관, 개인정보처리방침 등) |
| SNS | 미정 |

- 통신판매업 신고번호 등 법적 표기가 필요한지 확인해야 합니다.

## 404

- 구현 위치: `src/app/not-found.tsx` (아직 없음, Next.js 기본 화면 사용 중)
- 내용: 미정

## 미정

- 헤더·푸터 디자인과 메뉴 구성
- 다른 서비스(스토어 등)로 가는 링크를 헤더에 둘지
