# 0017. 메인은 매장 공간 이미지를 보여 주고 검색은 전용 페이지로 옮긴다

- 상태: 채택
- 날짜: 2026-10-12

## 배경

사용자는 메인 매장 섹션을 대표 이미지로 화면을 채우고 상단 검색에서 매장 페이지로 이동하도록 요청했습니다. ADR-0010의 메인 안 매장 검색·결과 방향을 변경합니다.

## 결정

- 메인의 매장 섹션은 기존 공간·외관 이미지 3장과 상단 검색으로 구성합니다.
- 검색은 `/stores?q=...`로 이동하며 결과·주소·연락처·개점일은 이 페이지에서 표시합니다.
- 페이지는 SSG를 유지하고 검색·지역 필터·페이지 번호는 클라이언트에서 URL을 읽습니다.
- 사용자가 생성한 100개 가상 매장 JSON은 `src/mocks/stores.json`에 보관합니다. 기존 예시 데이터 설정으로 미리보기에서만 사용하며 운영 데이터로 공개하지 않습니다.
- 실제 매장 데이터 출처는 아직 미정입니다. 기존 정적 공개 데이터 선택 경계를 유지합니다.

## 결과

메인의 높이는 매장 수와 무관합니다. 검색 조건을 공유하거나 뒤로 가기로 복원할 수 있습니다. 화면 규칙은 [메인](../pages/home.md)과 [매장 페이지](../pages/stores.md)가 기준입니다.
