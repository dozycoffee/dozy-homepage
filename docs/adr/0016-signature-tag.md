# 0016. 시그니처는 상품 태그로 구분한다

- 상태: 채택
- 날짜: 2026-10-12

## 배경

시그니처를 상품 그룹으로 묶었으나 사용자는 상품 그룹의 용도가 다르며 태그로 구분하도록 요청했습니다.

## 결정

- 시그니처 표시는 상품의 `tagNames`에 있는 시그니처 태그로 판단합니다.
- 허용 태그에 시그니처를 추가하며 상품당 태그 최대 2개 규칙은 유지합니다.
- 기존 시그니처 4종의 그룹 지정을 태그로 옮기고 시그니처용 상품 그룹 선언을 제거합니다.
- 상품 그룹 필드와 검증 계약은 유지하며 시그니처 필터에는 사용하지 않습니다.

## 결과

상품 카테고리와 태그를 함께 사용해 원래 분류와 시그니처 탭에 동시에 표시할 수 있습니다. 현재 계약은 [data-sources.md](../data-sources.md), 화면 동작은 [메뉴 페이지](../pages/menu.md)가 기준입니다.
