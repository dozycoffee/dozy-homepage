# 0015. 메인은 대표 메뉴만 표시하고 전체 조회는 메뉴 페이지로 옮긴다

- 상태: 채택 (메인 대표 카드는 [ADR-0018](0018-menu-ad-carousel.md)로 대체)
- 날짜: 2026-10-12

## 배경

메뉴가 늘어나면서 메인의 메뉴 섹션이 길어졌습니다. 사용자는 메인에 일부 대표 음료 이미지만 표시하고 전체 메뉴는 별도 페이지에서 조회하도록 요청했습니다. ADR-0010의 메뉴 섹션 내 전체 조회 방향을 변경합니다.

## 결정

- 메인은 선택한 대표 음료 3종과 전체 메뉴 링크만 표시합니다.
- 모바일은 한 줄 가로 스크롤, 넓은 화면은 한 줄 3열로 배치합니다.
- `/menu`에 전체 상품 조회·검색·분류를 제공합니다. 헤더의 메뉴 링크도 이 페이지로 연결합니다.
- 데이터는 기존 JSON/API 클라이언트로 브라우저에서 조회합니다. 페이지 골격은 SSG를 유지합니다.

## 결과

상품 수가 늘어도 메인 대표 카드 수는 늘지 않습니다. 이미지와 여백은 화면 높이를 고려하며 접근성 확대 상황에서는 내용을 자르지 않습니다. 현재 이미지와 메뉴는 시안입니다. 화면 규칙은 [메인](../pages/home.md)과 [메뉴 페이지](../pages/menu.md)가 기준입니다.
