# 0014. 메뉴 기획 JSON을 브라우저에서 조회한다

- 상태: 채택
- 날짜: 2026-10-12

## 배경

사용자가 제안 상품 20종을 음료·푸드·MD의 2단계 분류로 홈페이지에 반영하고, 코드에 데이터를 삽입하지 않고 클라이언트에서 불러와 향후 실제 API로 전환하도록 요청했습니다. 기존 ADR-0003의 정적/ISR 조회와 ADR-0013의 임시 메뉴 5종·가격 미공개 기준을 메뉴에 한해 변경합니다.

## 결정

- 상품·카테고리·옵션·상품 그룹을 독립 JSON 파일로 제공합니다.
- 페이지 골격은 SSG를 유지하고 메뉴 목록만 브라우저에서 조회합니다.
- 요청과 응답 검증은 API 클라이언트에 모으고 공개 조회 URL을 설정할 수 있게 합니다.
- 로딩·빈 목록·오류·재시도 및 요청 취소를 처리합니다.
- 현재 상품과 가격은 메뉴 기획안으로 반영합니다. 판매 확정 여부는 별도로 확인합니다.

## 결과

상품 데이터는 초기 HTML과 JavaScript 번들에 삽입되지 않습니다. JavaScript 실행과 조회 완료 후 메뉴가 표시됩니다. 향후 검색 노출을 위해 서버 초기 데이터가 필요해지면 렌더링 전략을 다시 검토합니다. 응답 계약과 연결 방법은 [data-sources.md](../data-sources.md)가 기준입니다.
