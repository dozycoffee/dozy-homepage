# 0012. 메인 섹션은 화면 높이를 채우고, 인터페이스는 상자 대신 글자와 선으로 만든다

- 상태: 채택
- 날짜: 2026-10-07

## 맥락

[ADR-0010](0010-single-page-home-sections.md)으로 만든 화면은 섹션 높이가 내용만큼이라 한 화면에 두 섹션이 걸쳐 보였습니다. 또 채운 버튼, 테두리 카드, 상자형 탭·검색창이 흔한 앱 위젯처럼 보여 브랜드 홈페이지다운 인상이 약했습니다. 매머드커피 홈페이지처럼 행동 요소를 글자·선·사진으로 보여 주는 방향을 원했습니다.

## 결정

- 메인의 모든 섹션은 고정 헤더 아래 화면 높이(`100svh - 헤더`)를 최소 높이로 채우고, 내용은 세로 가운데에 둡니다. 내용이 길면 늘어납니다. 모든 화면 너비에 적용합니다.
- 스크롤 스냅은 쓰지 않습니다.
- 버튼은 상자·배경 없이 글자 + 화살표 선(주요 행동) 또는 밑줄 글자(보조 행동)입니다.
- 탭은 밑줄 인덱스, 검색창은 밑줄 하나와 글자형 검색 버튼입니다.
- 메뉴·매장·소식은 테두리 카드 없이 둥근 사진(16px)과 그 아래 글자로 보여 줍니다. 빈 상태 안내도 상자 없이 위 구분선과 글자입니다.
- 매머드커피의 사선 그래픽, 색, 레이아웃은 따라 하지 않고 "상자 대신 글자와 선" 원칙만 참고합니다.

## 검토한 대안

- `md` 이상만 화면 높이: [ADR-0008](0008-full-screen-sections-with-snap.md)처럼 모바일을 뺄 수 있지만, 스냅이 없으면 모바일에서 내용을 건너뛰는 문제가 없어 모든 너비에 적용합니다.
- 화면 높이 + 스냅: 매장 목록처럼 길이가 바뀌는 섹션에서 스냅이 내용을 건너뜁니다.
- 버튼 모양 유지하고 모서리만 줄이기: 여전히 앱 위젯처럼 보입니다.

## 결과

- ADR-0010의 "화면 높이 섹션을 쓰지 않는다", ADR-0009의 버튼 모서리 8px·카드 테두리 규칙을 대체합니다. 나머지(섹션 구성, 색상, 이미지 패널 모서리)는 유지합니다.
- 내용이 적은 섹션은 위아래 여백이 커집니다.
- 값과 규칙은 [design-system.md](../design-system.md)가 기준입니다.
