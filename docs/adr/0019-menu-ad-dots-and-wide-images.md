# 0019. 광고 선택은 원형 버튼, PC 이미지는 높이에 맞춘다

- 상태: 채택
- 날짜: 2026-10-12

## 배경

사용자는 화살표로 넘기는 제어를 제거하고, 시간에 따른 자동 전환과 이미지 하단의 원형 인덱스 버튼을 요청했습니다. PC 이미지는 좌우가 더 넓어야 하며 높이를 섹션에 맞추고 좁은 화면에서는 좌우를 자르도록 요청했습니다.

## 결정

- 이전·다음 버튼과 별도 제어 행을 제거하고 원형 선택 버튼을 이미지 하단에 겹칩니다.
- 데스크톱은 호버·키보드 초점 때 버튼을 표시하며 모바일에서는 항상 표시합니다. 선택 버튼은 더 밝게 표시합니다.
- 원형 버튼으로 선택한 뒤에도 자동 전환을 이어갑니다. 접근성 일시정지 제어는 키보드 초점 때 표시합니다.
- 기존 구도를 유지하면서 좌우 배경을 확장한 약 3:1 PC 광고를 새 파일로 제공합니다. 높이 100%, 너비 auto, 중앙 정렬로 좌우를 잘라 표시합니다.
- 모바일은 기존 세로형 이미지를 사용하며 이미지 클릭은 메뉴 페이지로 이동합니다.

## 결과

ADR-0018의 데스크톱 contain과 화살표·제어 행 규칙을 대체합니다. 현재 동작·토큰은 [메인](../pages/home.md)과 [디자인 시스템](../design-system.md)이 기준입니다.
