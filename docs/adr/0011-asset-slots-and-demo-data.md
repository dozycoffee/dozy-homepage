# 0011. 이미지는 정해진 파일명 자리에 두고, 예시 데이터는 운영 데이터와 분리한다

- 상태: 채택 (메뉴 공개 기준은 [ADR-0013](0013-full-bleed-hero-translucent-header-temp-menu.md)으로 대체)
- 날짜: 2026-10-07

## 맥락

브랜드 사진과 실제 메뉴·매장·소식 데이터가 아직 없습니다. 명세는 이미지가 없어도 깨진 이미지나 레이아웃 붕괴가 없고, 파일을 정해진 이름으로 넣으면 코드 수정 없이 보이길 요구합니다. 또 확정되지 않은 메뉴·매장·소식을 실제 정보처럼 공개하면 안 됩니다.

## 결정

- 이미지는 `public/assets/images/`에 명세의 파일명으로 둡니다. 서버 컴포넌트가 렌더링할 때 파일이 있는지 확인하고, 없으면 같은 비율의 배경색 자리만 그립니다. 페이지는 정적 생성이라 빌드 시점에 확인하고, 개발 서버는 요청마다 확인합니다.
- 공유 이미지(OG)와 파비콘도 파일이 있을 때만 metadata에 넣습니다.
- 공개용 데이터는 `src/content/`, 화면 확인용 예시는 `src/mocks/`에 둡니다. 예시는 `SHOW_DEMO_DATA=true`일 때만 쓰고, `SITE_ENV=production`이면 항상 쓰지 않습니다.
- 값이 없는 회사 정보, 링크, 가격 등은 화면에서 뺍니다. `#` 링크를 만들지 않습니다.

## 검토한 대안

- 브라우저에서 이미지 로드 실패(`onError`) 시 대체: 깨진 이미지가 잠깐 보이고, 모든 이미지가 클라이언트 컴포넌트가 됩니다.
- 예시 데이터를 운영 데이터 파일에 표시만 해 두기: 실수로 운영 화면에 나올 수 있습니다.

## 결과

- 이미지를 추가·교체하면 다시 배포해야 반영됩니다.
- 외부 주소(CDN) 이미지는 아직 지원하지 않습니다. 쓰게 되면 `next.config.ts`의 `images.remotePatterns`와 함께 정합니다.
- 규칙은 [design-system.md](../design-system.md#이미지), [configuration.md](../configuration.md#환경-변수)가 기준입니다.
