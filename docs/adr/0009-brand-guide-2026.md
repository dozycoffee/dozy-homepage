# 0009. 새 브랜드 기준(색상 5개, 커피콩 심볼)으로 디자인 토큰을 다시 정한다

- 상태: 채택 (버튼 모서리·카드 테두리는 [ADR-0012](0012-full-height-sections-and-typographic-ui.md)로 대체)
- 날짜: 2026-10-07

## 맥락

[ADR-0005](0005-tech-blog-based-design-tokens.md)는 정식 브랜드 가이드가 없어 기술 블로그의 색상을 빌려 썼습니다. 이번에 브랜드 디자인과 콘셉트를 새로 정한 메인 홈페이지 작업 명세가 나왔습니다. 명세는 색상 5개, 서체, 모서리, 로고 사용 규칙을 정합니다.

## 결정

- 색상 토큰은 명세의 5개(Cream, Espresso, Warm White, Caramel, Oat)만 씁니다. Tailwind 기본 팔레트는 지웁니다.
- 글자는 Espresso가 기본입니다. Caramel과 Oat는 작은 글자에 쓰지 않고 장식·구분선에만 씁니다.
- 서체는 Pretendard Variable을 유지합니다(사이트가 직접 제공).
- 모서리는 카드 16px, 큰 이미지 패널 24px, 버튼 8px입니다. 진한 그림자를 쓰지 않습니다.
- 로고는 D가 없는 커피콩 심볼(가운데 z 홈의 양 끝이 외곽으로 열린 형태)과 `Dozy Coffee` 글자입니다. 회전하거나 비율을 바꾸지 않습니다. 심볼 파일이 없으면 글자만 씁니다.
- 시바견 캐릭터와 이를 담은 시안 사진은 쓰지 않습니다.
- 다크 모드는 지원하지 않습니다.

## 검토한 대안

- 기술 블로그 색상 유지 (ADR-0005): 새 브랜드 기준과 색이 달라 두 기준이 섞입니다.
- 명세 색상에 보조 회색 추가: 본문 대비를 맞추기 쉽지만 브랜드 기준에 없는 색이 늘어납니다. 보조 글자도 Espresso를 쓰고 크기와 굵기로 위계를 만듭니다.

## 결과

- 기술 블로그와 홈페이지의 색이 달라집니다.
- 값과 규칙은 [design-system.md](../design-system.md)가 기준입니다.
