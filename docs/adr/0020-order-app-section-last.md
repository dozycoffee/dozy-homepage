# 0020. 오더앱 안내 섹션을 메인 맨 아래로 옮긴다

- 상태: 채택
- 날짜: 2026-10-12

## 배경

오더앱은 출시 예정(`COMING SOON`)이라 방문 고객이 바로 쓸 수 있는 기능이 없습니다. 사용자는 이 섹션을 메인 맨 아래로 옮기도록 요청했습니다.

## 결정

- 메인 섹션 순서를 히어로, 메뉴, 브랜드·공간, 매장 찾기, 소식, 가맹 안내, 오더앱으로 바꿉니다. 섹션 ID는 그대로입니다.
- 헤더의 `오더앱` 링크(`/#order-app`)는 그대로 유지합니다.

## 결과

[ADR-0010](0010-single-page-home-sections.md)의 섹션 순서를 대체합니다. 현재 순서는 [메인 명세](../pages/home.md)가 기준입니다.
