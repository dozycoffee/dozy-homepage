# 0003. 페이지는 정적 생성을 기본으로 하고 바뀌는 데이터만 ISR을 쓴다

- 상태: 채택
- 날짜: 2026-10-06

## 맥락

홈페이지 내용은 대부분 배포할 때만 바뀝니다. 공개 사이트라 첫 화면 속도와 검색 노출이 중요합니다. 나중에 상품·원두 정보처럼 배포와 상관없이 바뀌는 데이터를 보여 줄 수 있습니다.

## 결정

- 모든 페이지는 정적 생성(SSG)이 기본입니다.
- 외부 데이터가 배포와 상관없이 바뀌는 페이지만 ISR을 씁니다.
- 요청마다 렌더링하는 동적 렌더링은 지금 쓰지 않습니다. 필요해지면 새 ADR을 씁니다.

## 검토한 대안

- 모든 페이지 동적 렌더링: 항상 최신이지만 요청마다 서버 비용과 지연이 생기고, 외부 API 장애가 바로 화면 장애가 됩니다.

## 결과

- 페이지 문서의 "렌더링" 항목에 방식을 씁니다. SSG가 아니면 이유를 씁니다.
- 기준과 예시는 [architecture.md](../architecture.md#렌더링)에 있습니다.
