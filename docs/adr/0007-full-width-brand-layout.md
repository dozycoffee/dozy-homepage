# 0007. 메인 화면은 전체 폭 비주얼과 공통 정렬선으로 만든다

- 상태: 대체됨(→ 0010)
- 날짜: 2026-10-06

## 맥락

[ADR-0006](0006-magazine-layout.md)의 매거진형 화면은 사진을 1440px 안에 두고 글을 작게 두어, 커피 브랜드 홈페이지로서 첫인상이 약했습니다. 매머드커피, 스타벅스 코리아처럼 화면 전체 폭을 쓰는 비주얼과 큰 섹션 규모가 필요합니다. 색상과 폰트는 [ADR-0005](0005-tech-blog-based-design-tokens.md)를 유지합니다.

## 결정

- 사진과 섹션 배경은 브라우저 좌우 끝까지 채우고, 글과 메뉴는 공통 정렬선(좌우 6vw, 모바일 24px, 최대 1440px)을 따릅니다.
- 첫 화면은 전체 폭 대표 사진 한 장 위 왼쪽에 제목, 설명, 버튼 하나를 둡니다. 높이는 화면에 맞춰 480~720px입니다.
- 브랜드 소개는 사진 60% : 글 40%의 맞닿은 분할 화면입니다.
- 소식은 짧은 섹션으로, 가로선 목록을 씁니다.
- 헤더는 상단에 고정합니다.
- 제목은 굵기 600으로 크게, 버튼은 모서리 4px로 둡니다.
- 참고한 브랜드의 색상, 그래픽, 레이아웃을 복제하지 않습니다.

## 검토한 대안

- 매거진형 유지 (ADR-0006): 차분하지만 사진이 작아 보이고 브랜드 첫인상이 약합니다.
- 자동 슬라이드나 배경 영상: 움직임이 많고 성능 부담이 큽니다. 대표 이미지 한 장으로 둡니다.

## 결과

- 첫 화면 품질이 대표 사진 한 장에 크게 좌우됩니다. 데스크톱과 모바일 구도를 따로 준비해야 합니다.
- 사진 위 글자 대비를 위해 국소 오버레이가 필요합니다.
- 값과 규칙은 [design-system.md](../design-system.md)가 기준입니다.
