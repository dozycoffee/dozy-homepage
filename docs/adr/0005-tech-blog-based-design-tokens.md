# 0005. 디자인 토큰은 기술 블로그의 색상과 Pretendard를 기준으로 한다

- 상태: 채택
- 날짜: 2026-10-06

## 맥락

조직에 정식 브랜드 가이드나 디자인 시스템이 없습니다. 이미 있는 화면은 두 곳입니다.

- 기술 블로그(`dozycoffee.github.io`): 공개 사이트. 브라운 강조색 `#8b5e34`, 회색 글자, 흰 배경, Pretendard.
- 어드민 콘솔(`dozy-admin-console`): 로그인 뒤 쓰는 관리 화면. 다른 브라운 값(`#674638`, `#241914`), 따뜻한 회백색 배경, Inter + Pretendard.

두 곳 모두 커피 브라운 계열과 Pretendard를 쓰지만 색 값은 다릅니다.

## 결정

- 색상 토큰은 기술 블로그의 값을 그대로 가져옵니다.
- 폰트는 Pretendard Variable입니다. `pretendard` npm 패키지의 dynamic subset CSS를 import해 사이트가 직접 제공합니다.
- 다크 모드는 지원하지 않습니다.
- 정식 브랜드 가이드가 나오면 새 ADR로 이 결정을 대체합니다.

## 검토한 대안

- 어드민 콘솔 값: 관리 화면용이라 사이드바처럼 아주 진한 색이 중심이고, 공개 사이트와 성격이 다릅니다.
- 두 곳의 값을 섞어 새로 정함: 기준이 셋으로 늘어납니다.
- 폰트를 `next/font/google`로 불러옴: Google Fonts에 Pretendard가 없습니다. 처음 잡았던 Noto Sans KR은 다른 두 화면과 폰트가 달라집니다.
- 기술 블로그처럼 CDN(jsDelivr)에서 폰트 CSS를 불러옴: 외부 요청이 늘고 CDN 장애에 영향을 받습니다.

## 결과

- 기술 블로그와 홈페이지가 같은 색과 폰트로 보입니다.
- 토큰 값과 사용 규칙은 [design-system.md](../design-system.md)가 기준입니다.
- 어드민 콘솔과는 색 값이 다릅니다. 토큰 공유는 나중에 정합니다.
