# 0018. 메뉴 광고 이미지를 구도가 다른 슬라이드로 표시한다

- 상태: 채택 (제어와 PC 이미지 표시 방식은 [ADR-0019](0019-menu-ad-dots-and-wide-images.md)로 일부 대체)
- 날짜: 2026-10-12

## 배경

사용자는 서체까지 포함한 메뉴별 광고 이미지를 여러 장 만들고 좌우로 회전해 표시하도록 요청했습니다. 생성된 세 장의 구도가 비슷하다는 의견에 따라 각 광고의 카메라·제품 위치를 다르게 구성했습니다. ADR-0015의 대표 음료 카드와 ADR-0012의 자동 슬라이드 금지를 메뉴 섹션에 한해 변경합니다.

## 결정

- 누룽지는 큰 잔 측면, 흑임자는 크림 오버헤드, 유자말차는 햇빛 아래 왼쪽 잔 전체와 오른쪽 카피를 사용합니다.
- 서체와 카피를 광고 이미지에 포함하고 가로형·세로형을 별도 제공합니다.
- 메인 광고는 정적 캠페인 이미지이며 상품 목록은 기존 메뉴 페이지에서 클라이언트 조회합니다.
- 자동 전환과 직접 이동·일시정지 제어를 제공하고 움직임 줄이기, 키보드 초점, 화면 가시성을 존중합니다.

## 결과

상품이 늘어도 메인에는 광고 세 장만 표시합니다. 생성 이미지는 제품 기획 시안입니다. 현재 동작과 규격은 [메인](../pages/home.md)과 [디자인 시스템](../design-system.md)이 기준입니다.
