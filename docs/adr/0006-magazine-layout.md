# 0006. 메인 화면은 사진 중심의 매거진 형태로 만든다

- 상태: 대체됨(→ 0007)
- 날짜: 2026-10-06

## 맥락

첫 mock 화면은 둥근 카드, 알약 버튼, 같은 폭의 섹션, 굵은 제목으로 만들었습니다. 이런 구성은 흔한 랜딩 템플릿처럼 보여 Dozy만의 인상이 남지 않습니다. 색상과 폰트는 [ADR-0005](0005-tech-blog-based-design-tokens.md)로 정해져 있습니다.

## 결정

- 커피와 공간 사진을 크게 보여 주고, 그 사이에 짧은 글을 두는 매거진 형태로 만듭니다.
- 스크롤 순서는 공간의 분위기 → 브랜드의 생각 → 최근 소식입니다.
- 색상과 Pretendard는 유지하고, 레이아웃·타이포·여백·모서리 규칙을 새로 정합니다.
  - 넓은 사진 영역(1440px)과 좁은 읽기 영역(1120px)을 나눕니다.
  - 제목은 크지만 중간 굵기로, 본문은 17px에 행간 1.7로 둡니다.
  - 사진과 목록은 직각이고, 링크는 밑줄과 화살표로 표시합니다.
  - 움직임은 링크 반응 정도로 제한합니다.

## 검토한 대안

- 첫 mock 화면(카드형 랜딩): 만들기 쉽지만 템플릿처럼 보입니다.

## 결과

- 사진의 질과 글의 내용이 화면 품질을 크게 좌우합니다. 사진마다 역할이 다르고, 글마다 실제로 할 이야기가 있어야 합니다.
- 수치는 시안 제안값입니다. 값과 규칙은 [design-system.md](../design-system.md)가 기준입니다.
