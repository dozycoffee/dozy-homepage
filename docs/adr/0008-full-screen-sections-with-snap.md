# 0008. 메인 섹션은 화면 높이로 채우고 섹션 단위로 스냅한다

- 상태: 대체됨(→ 0010)
- 날짜: 2026-10-06

## 맥락

[ADR-0007](0007-full-width-brand-layout.md)의 개편 명세는 "모든 섹션을 화면 높이로 만들지 않는다", "소식은 짧게", "강제 화면 단위 스크롤을 쓰지 않는다"였습니다. 실제 화면을 보니 섹션마다 높이가 달라 한 화면에 두 섹션이 걸쳐 보였고, 첫 화면처럼 각 섹션을 한 장씩 넘겨 보는 구성이 더 낫다고 판단했습니다.

## 결정

- `md`(768px) 이상에서 메인의 브랜드 소개와 소식은 각각 고정 헤더 아래 화면 높이를 채웁니다. 내용이 길면 늘어납니다.
- 같은 범위에서 섹션 단위 스크롤 스냅(`scroll-snap-type: y mandatory`)을 씁니다. 첫 화면, 브랜드 소개, 소식은 시작점, 푸터는 끝점에 맞춥니다.
- 모바일은 화면 높이 섹션과 스냅을 쓰지 않습니다.
- ADR-0007의 섹션 높이와 스크롤 관련 부분만 대체합니다. 전체 폭 비주얼, 정렬선, 분할 비율 등 나머지는 유지합니다.

## 검토한 대안

- 화면 높이만 맞추고 일반 스크롤: 강제성이 없지만, 섹션 경계에서 멈추지 않아 한 화면에 두 섹션이 걸칩니다.
- `proximity` 스냅: 경계 근처에서만 붙어 덜 강제적이지만, 원하는 "한 장씩 넘기는" 느낌이 약합니다.
- 모바일에도 스냅: 브랜드 소개가 화면보다 길어 내용을 건너뛰거나 되돌릴 수 있습니다.

## 결과

- 소식처럼 내용이 적은 섹션은 여백이 커집니다. 내용은 세로 가운데에 둡니다.
- 새 섹션을 추가할 때 `data-snap`을 붙여야 스냅 흐름에 들어갑니다.
- 값과 규칙은 [design-system.md](../design-system.md)가 기준입니다.
