# 0010. 메인은 7개 섹션을 한 페이지에 두고, 헤더 메뉴는 섹션으로 이동한다

- 상태: 채택 (섹션 높이는 [ADR-0012](0012-full-height-sections-and-typographic-ui.md), 헤더 배경·히어로 패널은 [ADR-0013](0013-full-bleed-hero-translucent-header-temp-menu.md)으로 대체)
- 날짜: 2026-10-07

## 맥락

[ADR-0007](0007-full-width-brand-layout.md)과 [ADR-0008](0008-full-screen-sections-with-snap.md)은 전체 폭 사진 위주의 3개 섹션(첫 화면, 브랜드, 소식)과 화면 단위 스냅이었습니다. 새 작업 명세는 방문 고객에게 메뉴와 매장 정보를 주고, 출시 예정 오더앱과 가맹 안내까지 한 페이지에서 소개하도록 정합니다. 상세 페이지는 별도 작업입니다.

## 결정

- 메인은 히어로, 메뉴, 오더앱, 브랜드·공간, 매장 찾기, 소식, 가맹 안내 순서의 한 페이지입니다. 섹션마다 고정 ID를 둡니다.
- 헤더 메뉴는 별도 페이지가 아니라 메인의 섹션(`/#id`)으로 이동합니다.
- 헤더는 `sticky`로 상단에 고정하고 배경은 항상 불투명합니다. 투명 헤더와 사진 겹침을 쓰지 않습니다.
- 본문은 최대 1200px 정렬선 안에 두고, 큰 이미지는 모서리 24px 패널, 목록은 모서리 16px 카드로 보여 줍니다. 섹션 배경색(Warm White, Cream)만 전체 폭입니다.
- 화면 높이 섹션과 스크롤 스냅을 쓰지 않습니다.
- 제목과 버튼은 이미지에 합성하지 않고 HTML로 씁니다. 자동 슬라이드를 쓰지 않습니다.

## 검토한 대안

- 섹션마다 상세 페이지를 두고 헤더가 페이지로 이동: 상세 페이지가 아직 없어 "준비 중" 페이지만 늘어납니다.
- 스냅 유지 (ADR-0008): 섹션이 7개로 늘고 매장 목록처럼 길이가 바뀌는 섹션이 생겨 스냅이 내용을 건너뜁니다.

## 결과

- ADR-0007과 ADR-0008을 대체합니다.
- 상세 페이지가 생기면 해당 헤더 메뉴의 목적지를 다시 정합니다.
- 섹션 구성은 [pages/home.md](../pages/home.md), 값은 [design-system.md](../design-system.md)가 기준입니다.
